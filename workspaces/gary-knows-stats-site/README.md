# Gary Knows Stats — Brunson Efficiency Lab

A one-file, mobile-first static site. Open `index.html` in any modern browser or publish it via GitHub Pages/any static host. No build step or API keys.

## Features
- Three source-checked NBA box score cards (Phoenix 2023, San Antonio 2024, Chicago 2026).
- Game-to-game FG%, approximate true shooting%, and points-per-FGA comparisons.
- Validated box-score calculator.
- Evidence-labeled private browser notes, JSON backup and import.
- Deliberately **no claims of live data**, cloud synchronization, or automatic fact-checking.

## Publishing
Place `index.html` at the document root of a static host. The site does not require dependencies.
