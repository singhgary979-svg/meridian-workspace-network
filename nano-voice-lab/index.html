Read-only preservation boundary

Do not infer the Nano footprint from the 1.5 GB full model. Do not deploy to learn whether inference works. A label such as “model ready” is not proof that the exact binaries and generation path are correct.

One genuine Nano-generated line

Two supported paths: call a user-verified Hugging Face Gradio Nano Space with its exact API name and arguments; or import audio actually generated outside this lab, accompanied by provenance. Neither route can certify source-model identity from sound alone.

The generation gate is closed until model and runtime evidence is verified.

Do not put silent direction tags into the model text unless the runtime explicitly supports them.

Live generation connector (optional)

Uses the independently configured Gradio Space, never the LIVEWIRE production URL. It sends text and any selected reference sample over the network only when you press Generate.

$TEST_LINE inserts the performed line. $REFERENCE_AUDIO sends the chosen voice reference using Gradio file upload. Field order must come from the actual API specification—there is no guessed default.
