# Meridian Integration Contract

1. Project identities are immutable unless explicitly migrated.
2. Never infer a saved state, verified fact, installed capability or continuity from a plugin title.
3. Original work is the default; cross-project reuse requires explicit user selection.
4. Keep research evidence, creative invention and personal reflection distinct.
5. Router resolves intent and emits a proposed target; invocation occurs only when an actual target tool is connected and authorized.
6. Master tracks a project index, handoff manifest, revision receipts and user-approved dependencies.
7. Export/import must be explicit, reversible and versioned; never silently overwrite.
8. Keep personal state outside public Git history.
9. A passing package validation is not proof of live MCP connectivity or app-view functionality.
